What triggers an alert

Lookout sends an alert here for two things: a moderation rule firing with the "alert" or "delete + alert" action, and a user escalation. A Slack webhook receives a plain {"text": "..."} payload with a human-readable summary. A generic webhook receives the full JSON payload, which additionally includes category and message fields for escalations.
