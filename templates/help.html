Getting started, in order

  1. Connect your Telegram bot — created via @BotFather. You must run /setprivacy → Disable before adding it to a group, or Lookout will silently see nothing.
  2. Configure an AI provider — bring your own OpenAI, Anthropic, or Gemini key. The assistant will not answer at all until this is set.
  3. Add a community — the numeric group chat ID, its language and its timezone.
  4. Upload knowledge (optional) — PDF, DOCX, TXT or Markdown the assistant can quote from.
  5. Connect integrations (optional) — Slack or a generic webhook for alerts.

The Setup checklist tracks all of this against your real project state.

Integrations: what triggers an alert

Lookout sends an alert for two things: a moderation rule firing with the "alert" or "delete + alert" action, and a user escalation. A Slack webhook receives a plain {"text": "..."} payload. A generic webhook receives the full JSON payload, which additionally includes category and message fields for escalations.

Knowledge retrieval

Retrieval matches on shared keywords, not meaning — it is not semantic search. If the assistant misses a document you uploaded, try rephrasing the question to use the same words the document uses.

Channels are post-only

An announcement channel is a posting destination only — moderation and the AI assistant run in the linked group, not the channel. Linking the channel to the group as its Telegram discussion group makes Telegram auto-forward channel posts into the group; that's native Telegram behaviour, and Lookout automatically ignores those auto-forwarded copies during moderation.

Troubleshooting

The bot ignores everything in the group. Privacy mode is still on, or the chat ID is wrong. Check the telegram-worker logs while sending a message — silence there means Telegram isn't delivering the update at all.

Telegram returns 409 Conflict. Something else is polling the same bot token, or a webhook is registered on it. Only one consumer can use getUpdates at a time.

The assistant replies that it can't answer reliably. The AI provider call is failing — check Post History or the AI settings page for the exact error, which now includes the provider's real error message rather than a generic HTTP code.

Moderation never fires. Confirm moderation is toggled on for that specific community, not just configured at the project level, and that the rule itself is enabled.
