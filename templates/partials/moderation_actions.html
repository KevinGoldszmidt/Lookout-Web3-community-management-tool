Enabled rules are checked in the order shown below, and only the first matching rule fires — later rules are not checked for that message. What each action does:

ActionEffect
AlertSends a notification to your connected integrations. The message is left alone and the assistant still replies if mentioned.
WarnReplies in the chat flagging the message. Does not delete it or alert integrations.
DeleteDeletes the message. Does not warn the user or alert integrations.
Delete + alertDeletes the message and sends a notification to your connected integrations.
Warn + deleteDeletes the message and replies in the chat flagging it. Does not alert integrations.

Every action except Alert stops further processing of that message — the assistant will not reply to it even if mentioned.
