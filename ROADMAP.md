# Lookout Roadmap

## Milestone 1: public-safe foundation (included here)

- Multi-organisation/project schema
- First-run owner setup
- Role model
- Telegram bot connection
- Unlimited language communities
- OpenAI / Anthropic / Gemini BYO keys
- Knowledge uploads and retrieval-grounded assistant
- Configurable agent personality and terminology
- Moderation rule toggles and actions
- Slack / generic webhook alerts
- Prebuilt + custom AI content automations
- Per-community timezone scheduling
- Post history
- Base analytics event model
- Docker Compose + PostgreSQL

## Milestone 2: production hardening

- Database migrations with Alembic
- CSRF protection and stronger session security
- Email invite / password reset flow
- Enforced community-scoped permissions
- API-key rotation UX
- Audit log
- Rate limits and Telegram flood handling
- Queue/retry layer for AI and Telegram delivery
- Automated integration tests
- Backup/restore tooling
- Privacy/data-retention controls

## Milestone 3: richer community intelligence

- Member joins/leaves and net growth
- DAU/WAU/MAU
- Unique active members
- Response and escalation resolution rates
- Topic classification
- Sentiment trends
- Knowledge-gap detection
- Content engagement and best-time analysis
- Moderator workload and repeat-offender reporting

## Milestone 4: integrations and content

- CoinMarketCap / CoinGecko market adapters
- Messari / news provider adapters
- Structured Telegram polls rather than text-only poll templates
- Media/image generation pipeline
- Website/help-centre URL ingestion
- Scheduled one-off posts and drafts
- QA/test-channel mirroring

## Milestone 5: expansion

- Discord adapter
- Trivia and competition module port
- Lookout Cloud deployment
- Billing/plan system if commercial SaaS is validated
